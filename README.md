# Creators Free Website

Welcome to the Creators Free website project! This project aims to provide a suite of free tools for creators, including a resume creator, blog section, and poster design tools.

## Project Structure

The project is organized as follows:

```
creators-free-website
├── src
│   ├── index.html               # Main landing page of the website
│   ├── resume-creator.html      # Tool for creating resumes and cover letters
│   ├── blog.html                # Blog section for creators
│   ├── posters.html             # Page for poster categories and subcategories
│   ├── css
│   │   ├── styles.css           # Main styles for the website
│   │   └── responsive.css       # Responsive design styles
│   ├── js
│   │   ├── main.js              # Main JavaScript functionality
│   │   ├── header-footer.js      # Dynamic header and footer loading
│   │   └── resume-form.js       # Functionality for the resume creator tool
│   └── components
│       ├── header.html          # Header component with navigation
│       └── footer.html          # Footer component with copyright info
├── posts
│   └── creators-guide.md        # Blog post or guide for creators
├── package.json                 # npm configuration file
├── .gitignore                   # Files and directories to ignore in version control
└── README.md                    # Project documentation
```

## Features

- **Dynamic Header and Footer**: The website includes a dynamic header and footer that are loaded into each page, ensuring a consistent look and feel.
  
- **Resume Creator Tool**: Users can create various types of resumes, including Indian style resumes, Europass resumes, and cover letters.

- **Blog Section**: A dedicated blog section provides articles and guides relevant to content creation, helping creators improve their skills.

- **Poster Design Tools**: The website features categories and subcategories for posters, including:
  - Festival Posters
  - Sale Offer Posters
  - Quote Makers

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies using npm:
   ```
   npm install
   ```
4. Open the `src/index.html` file in your web browser to view the website.
